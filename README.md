# Asif — Architectural 3D Visualization Portfolio

This is a responsive static portfolio website built with HTML, CSS, and JavaScript.

## Preview locally
1. Extract the ZIP file.
2. Open `index.html` in a browser.
3. An internet connection is needed for the Google Fonts; the portfolio images are stored locally in `images/`.

## Included portfolio images
- `images/living-dining.jpg` — open-plan living and dining
- `images/staircase-storage.jpg` — staircase and built-in storage
- `images/cafe-interior.jpg` — commercial café interior
- `images/guest-bedroom.jpg` — guest bedroom
- `images/kitchen-dining.jpg` — kitchen and dining
- `images/master-bedroom.jpg` — master bedroom

## Replace an image later
Keep the image in the `images` folder and either use the same filename to replace it, or edit the matching `src="images/filename.jpg"` in `index.html`. The homepage hero image is set in `style.css` as `background-image: url("images/living-dining.jpg")`.

## Update the online website
If you publish with GitHub Pages, upload/commit the updated `index.html`, `style.css`, and the `images` folder to your repository. Local edits alone do not update the online website.
